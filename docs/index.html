Install Standalone Binary & Transfer at Line Rate

Pre-built static amd64 and arm64 binaries for Linux and macOS are published on GitHub Releases with SHA-256 checksums.

bash — One-line installer (auto-detects Linux/macOS amd64/arm64 + verifies SHA-256) 
# Option 1: One-line installer (verifies SHA-256 checksum automatically)
curl -sSfL https://ehlerst.github.io/t3/install.sh | sh

# Option 2: Homebrew (macOS & Linux)
brew install --formula https://raw.githubusercontent.com/ehlerst/t3/main/Formula/t3.rb

# Option 3: Cargo
cargo install --git https://github.com/ehlerst/t3 t3-cli

# Option 4: Manual tarball download + SHA-256 verification
TARGET="t3-linux-amd64" # or t3-linux-arm64 | t3-darwin-arm64 | t3-darwin-amd64
curl -sSLO "https://github.com/ehlerst/t3/releases/latest/download/${TARGET}.tar.gz"
curl -sSLO "https://github.com/ehlerst/t3/releases/latest/download/${TARGET}.tar.gz.sha256"
sha256sum -c "${TARGET}.tar.gz.sha256"
tar xzf "${TARGET}.tar.gz" && sudo mv t3 /usr/local/bin/t3
bash — Drop-in s5cmd syntax with --stat and --json telemetry 
# Upload directory of shards to S3 (or RustStack at http://localhost:4566)
t3 --stat cp ./training-shards/ s3://ml-bucket/v1/shards/

# Download matching Parquet files with --exclude filter
t3 --stat cp --exclude "*.tmp" "s3://ml-bucket/v1/shards/*.parquet" ./local-shards/

# Incremental sync with stale object deletion
t3 --stat sync --delete ./local-shards/ s3://ml-bucket/v1/shards/

# "Beast Mode": Execute thousands of heterogeneous S3 operations in one shared worker pool
t3 --stat run batch-commands.txt

Systems Engineering

Why `t3` Beats `s5cmd` and `aws-cli`

Built specifically for `*nix` operating systems (`Linux`, `macOS`, `BSD`) to eliminate kernel-to-userspace memory copies, Go GC pauses, and unpatched `s5cmd` security/scale bugs.

🚀 Zero-Copy `mmap` & Streaming I/O

Avoids anonymous heap allocations and redundant page-cache copies on multi-megabyte transfers.

  • Uploads ≥ 1 MiB map kernel page-cache pages directly via libc::mmap(PROT_READ, MAP_SHARED) + MADV_SEQUENTIAL
  • Downloads stream directly from hyper's socket buffer to disk, reusing buffers in-place
  • L3-cache-aware large-stream semaphore prevents DRAM cache thrashing

🔐 Complete AWS Cloud Auth (IRSA + IMDSv2)

Unlike s5cmd (built on deprecated aws-sdk-go v1), t3 supports modern AWS authentication out of the box.

  • AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_SESSION_TOKEN
  • EKS IRSA: STS AssumeRoleWithWebIdentity via AWS_WEB_IDENTITY_TOKEN_FILE
  • EKS Pod Identity & ECS: AWS_CONTAINER_CREDENTIALS_FULL_URI
  • EC2 IMDSv2: Token-authenticated metadata credentials (169.254.169.254)
  • Profiles: ~/.aws/config & ~/.aws/credentials including credential_process and endpoint_url

🛡️ Security & Scale Fixes Over `s5cmd`

Fixes long-standing open bugs in unmaintained peak/s5cmd while preserving 100% CLI flag compatibility.

  • Path Traversal Guard: Rejects malicious S3 keys containing ../ (fixes s5cmd #872)
  • S3-to-S3 Copy > 5 GiB: Automatic parallel UploadPartCopy (fixes s5cmd #29)
  • Filter-Safe Sync Delete: sync --delete strictly honors --exclude / --include (fixes s5cmd #815)
  • Cached SigV4 Key: Derives daily HMAC key once per region (~221,000+ signings/sec/core)

All 15 `s5cmd` Subcommands Supported

Global flags (--numworkers, --endpoint-url, --stat, --json, --dry-run, --profile) work either before or after the subcommand.

cpTransfer
Parallel upload, streaming/range download, and S3-to-S3 multipart copy (> 5 GiB).
syncDiff Engine
Concurrent source & destination listing diff with --delete, --size-only, --exact-timestamps.
mvTransfer
High-speed parallel copy followed by atomic source deletion.
lsListing
Bucket & prefix listing with speculative Delimiter=/ fan-out, -e, -H, -s.
rmBatch Delete
Pipelined 1,000-key DeleteObjects batcher across wildcards and versions.
runBeast Mode
Executes batch commands from file or stdin concurrently on the shared worker pool.
catStreaming
Streams one or more S3 objects (including wildcards) directly to stdout.
pipeStreaming
Streams stdin directly to an S3 object via bounded-memory parallel multipart upload.
duAnalytics
Summarizes total bytes and object counts with storage-class grouping (-g, -H).
headMetadata
Inspects HeadBucket or HeadObject ETag, size, and user metadata.
mb / rbBuckets
Creates or removes S3 buckets (rb --force empties bucket before removal).
presignAuth
Generates SigV4 query-authenticated presigned GET URLs with custom expiry.
selectQuery
Executes SQL projections and filters across JSON/NDJSON and CSV objects.
bucket-versionVersioning
Gets or sets (Enabled / Suspended) bucket versioning configuration.
versionCLI
Prints build version and --install-completion scripts for bash, zsh, and fish.
